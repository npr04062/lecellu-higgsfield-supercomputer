# Le Cellu × Higgsfield Supercomputer

르셀루의 36.5초 한국어 색상 조합 릴스를 Higgsfield Supercomputer에서 제작하기 위한 비공개 원샷 패키지다.

## 가장 빠른 사용법

1. Higgsfield Supercomputer에 이 저장소를 연결하거나 저장소 전체 ZIP을 한 번에 업로드한다.
2. [START-HERE.md](START-HERE.md)의 `Supercomputer 원샷 실행문` 한 문장을 입력한다.
3. 계획·콘택트시트·음성·최종 영상의 네 승인 지점에서만 확인한다.

Supercomputer 계정에서 GitHub 저장소 직접 불러오기가 보이지 않으면 GitHub의 `Code → Download ZIP`으로 받은 파일을 업로드한다. ZIP 내부 구조를 변경하지 않는다.

## 구성

- [SKILL.md](SKILL.md): 실행 순서, 승인 규칙, 고정 조건
- [START-HERE.md](START-HERE.md): 한 줄 시작 명령
- [references/master-prompt-ko.md](references/master-prompt-ko.md): 전체 한국어 제작 프롬프트
- `assets/reference-video.mp4`: 원본 레퍼런스 영상
- `assets/lecellu-store-reference.mp4`: 르셀루 실제 공간 영상
- `assets/lecellu-cast-reference-1080x1920.png`: 한국인 3인 기준 사진

## 보안

이 저장소에는 거래처 매장 영상이 포함되어 있다. private 상태를 유지하고, 결과물의 외부 게시나 공유는 별도 승인 후 진행한다.
