# Le Cellu Higgsfield Supercomputer

Create a 36.5-second vertical Korean fashion reel using the files in this package. Read [START-HERE.md](START-HERE.md) and [references/master-prompt-ko.md](references/master-prompt-ko.md) completely before planning or generating.

## Inputs

- `assets/reference-video.mp4`: use only for timing, three-person composition, wardrobe-change rhythm, restrained gesture style, and subtitle placement.
- `assets/lecellu-store-reference.mp4`: use as the Le Cellu fitting-room/showroom location reference.
- `assets/lecellu-cast-reference-1080x1920.png`: highest-priority identity, age, body-proportion, left-center-right placement, and camera reference.
- `references/master-prompt-ko.md`: authoritative script, shot timing, wardrobe map, voice direction, subtitles, repair prompts, and QC checklist.

## Required workflow

1. Verify all three assets are readable and analyze them without generating.
2. Present the planned models, steps, deliverables, and estimated credit cost. Stop for explicit approval before spending credits.
3. Generate the ten wardrobe stills with locked cast, location, and camera. Present one contact sheet and stop for approval.
4. Generate one continuous Korean master-tailor voice track from the exact approved script. Present the voice preview and stop for approval.
5. Animate the approved stills, assemble hard jump cuts, add the tailor close-up, apply lip sync only to the tailor, and add Korean text as editable post-production layers.
6. Run every item in the master prompt's final checklist. Repair only failed shots or stages.
7. Deliver a 1080×1920, 9:16, 30fps, 36.5-second master with no letterboxing, watermark, invented logo, or source-app CTA.

## Invariants

- Exactly three fictional Korean people: elderly male tailor left, female model center, male model right.
- Lock their faces, ages, hair, bodies, positions, and the Le Cellu location across every shot.
- Keep the tailor's wardrobe, glasses, yellow tape measure, and voice unchanged. Change only the two models' garments between looks.
- Use the reference video's vintage shop only as pacing inspiration; never reproduce that wooden interior or its people.
- Do not generate Korean text inside image or video models. Add the exact supplied text after visual generation.
- Use the exact Korean narration and Le Cellu replacement CTA from the master prompt.
- Do not publish, post, share, or distribute the final output without separate user approval.

## Failure handling

If an identity, background, wardrobe color, Korean spelling, duration, or lip-sync check fails, use the corresponding repair prompt in `references/master-prompt-ko.md`. Retry only the failed item, and stop after three unsuccessful attempts with the failed artifact and a concise explanation.
